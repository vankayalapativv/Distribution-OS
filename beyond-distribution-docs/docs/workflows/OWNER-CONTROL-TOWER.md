# Owner Control Tower Flow

## Purpose

Provides Super Admin with full business visibility and control.

## Flow

```text
Live business data
        ↓
Track executives, locations, visits, collections
        ↓
Detect risk
        ↓
Highlight issues
        ↓
Display dashboard
        ↓
Enable decisions and approvals
```

## Role

Super Admin only.

## Key Capabilities

- full dashboard
- user management
- team/territory assignment
- rule configuration
- approval configuration
- incentive configuration
- GPS overview
- collection risk overview
- performance review
- exception handling

## Key Tables

- users
- teams
- territories
- customers
- visits
- gps_sessions (as-built name: gps_tracking_sessions)
- gps_points
- invoices
- collections
- alerts
- rule_definitions
- approval_requests
- incentive_plans
