**Repo: `Distribution-OS`.** New **Stock** bottom tab in the mobile app showing **available on-hand stock** (the distributor's warehouse stock), read-only. Commit `5177f15` on `main` (pushed). **API DEPLOYED prod** (`distribution-os-api` v`70500936`) + **OTA published** (production channel, runtime `0.0.2`, update group `b67f89be`, otaBuild bumped `0.0.2.0`→`0.0.2.1`). Verified live on prod by the user.

**Decisions (user):** audience = **SALES_EXECUTIVE + in-app admin** (= SUPER_ADMIN; `MOBILE_ROLES=["SALES_EXECUTIVE","LOGISTICS","SUPER_ADMIN"]`, so admin-in-app means SUPER_ADMIN — NOT logistics, NOT manager who's web-only). Detail = **pack-size + per-godown** breakdown. **View-only.** **Online-only** ("fresh every time I open the tab" — no disk cache). Presentation = a **6th bottom tab** (accordion "Design A", chosen from a 3-option artifact mockup). Built the artifact mockups FIRST, user picked A, then built.

**API (`apps/api`):** `GET /stock/available` → `listAvailableStock(sql)` in `services/stock.ts`. Returns `{ godowns:[{id,name}], products:[{productId,productName,brand,segment,unit,totalUnits,packs:[{packSizeLitres,totalUnits,byGodown:[{locationId,qtyUnits}]}]}] }`. Only products/packs with stock (`qty_units>0`); **byGodown lists ONLY godowns that hold that pack** (dropped the fill-all-godowns-with-0 — prod has 5 godowns but stock mostly in "Main Godown", so zeros were noise). Reuses `stock_balances`. Auth `requireRole(["SALES_EXECUTIVE","SUPER_ADMIN","MANAGER"])`. ⚠️ All `/stock/*` sit behind `v1.use("/stock/*", sectionGuard("stock"))`, but `sectionGuard` only enforces for **configurable roles** (`CONFIGURABLE_ROLES=["MANAGER","ACCOUNTANT"]`) — SE + SUPER_ADMIN pass through to `requireRole`; ACCOUNTANT 403s at the guard, LOGISTICS 403s at requireRole. Test in `routes/stock.test.ts` (mock the service; assert se/superAdmin 200, logistics/accountant 403).

**Mobile (`apps/mobile`):** `lib/stock.ts` (types + `fetchAvailableStock` + `packLabel` "5 L"/"pcs"), `lib/use-available-stock.ts` (plain `useQuery`, `staleTime:0`, `useFocusEffect` refetch, client-side name/brand filter — online-only, NOT the cached-query helper), `components/stock/{stock-screen,stock-row,stock-skeleton}.tsx`, `app/(tabs)/stock.tsx` + `app/(admin)/stock.tsx` (both render shared `StockScreen`), tab added to BOTH `(tabs)/_layout.tsx` + `(admin)/_layout.tsx` with `cube`/`cube-outline` icon. Accordion: collapsed row = name · (segment · brand) · total units + chevron; expand → each pack with "{u} u · {litres} L" total + per-godown dot/name/qty. JS-only (no native) → OTA-safe.

**⚠️ NativeWind gotcha (cost a round-trip):** `border-border/60` (opacity modifier on a CSS-var color) **does NOT resolve in NativeWind/RN and falls back to BLACK** → heavy dark dividers. Use `border-border` (no `/60`). Also the app is **light-only** (`app.json userInterfaceStyle:"light"`); tokens in `src/global.css` (`--background:#fff`, `--secondary:#f3f4f6`, `--muted:#f9fafb`, `--border:#e5e7eb`, `--foreground:#333`). To match a WHITE artifact use `bg-background` (list screens often use `bg-secondary` grey + white cards, but Stock is a flat white list).

**E2E tested locally first** (user's preference): local API (`pnpm --filter api dev`, root `.env`=PROD DB per [[local-dev-uses-live-prod]]) on :8787, wrangler **hot-reloads** route edits; mobile `.env` already `EXPO_PUBLIC_API_URL=http://10.0.2.2:8787/api/v1` (emulator→host). Dev build via `pnpm --filter mobile android` (= `expo run:android`, Zulu17, Pixel_8 `emulator-5554`) — the installed RELEASE APK won't load new JS, must uninstall it first (signature clash) + run a debug build; Metro fast-refresh applies edits live. Real prod data: ~10 products in Main Godown (Fuchs Titan GT1 1L=73/4L=39, etc.). Login is the user's (prod Neon Auth; tested as `priya.se@vardhandemo.test`).

**OTA mechanics (DOS):** `runtimeVersion:{policy:"appVersion"}` → runtime = app version "0.0.2" — **NO fingerprint-pin dance** (that's Sri-Aparajita's `fingerprint` policy only; see [[expo-ota-updates]]). Publish: `eas update --channel production --platform android --environment production --message "…"` — **`--environment production` is REQUIRED** so the bundle uses the EAS prod env (`EXPO_PUBLIC_API_URL`=prod worker) and NOT the local `.env` (10.0.2.2). ⚠️ OTA only reaches phones on the **0.0.2 build**; older builds need the APK first. Deploy the API BEFORE the OTA (OTA'd app calls prod `/stock/available`). Related: [[mcp-settings-page]] isn't relevant; see [[android-emulator-and-ota-testing]].
