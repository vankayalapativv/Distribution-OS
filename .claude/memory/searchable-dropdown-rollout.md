Ongoing (started 2026-11-01): make **every dropdown in `apps/web` the app's searchable dropdown** — user wants `SearchSelect` (the one WITH a search box) everywhere, even tiny 2-option ones (e.g. the Stock "All godowns" filter). Web only (mobile is RN, separate). Rollout is **page by page, user approves each**.

**Canonical component (promoted 2026-11-01):** the real implementations now live at `@/components/ui/search-select.tsx` (`SearchSelect`) + `@/components/ui/search-combobox.tsx` (`SearchCombobox`, the popover primitive, formerly `OrderSearchCombobox`). The old feature paths `@/features/orders/search-select` and `@/features/orders/order-search-combobox` are now **thin re-export shims** so the ~25 existing importers + their `vi.mock(...)` paths keep working untouched. NEW/converted code imports from `@/components/ui/*`; migrate old import paths opportunistically. `SearchSelect` gained optional `triggerClassName` + `disabled` props during the move (no behavior change for existing callers). NOTE: the app also has `@/components/text-select.tsx` (`TextSelect`) — same styling, NO search box, for fixed enums — but per the "searchable everywhere" instruction we use `SearchSelect`, not `TextSelect`, for conversions.

**Conversion recipe:** replace `<Select>/<SelectTrigger>/<SelectItem>` (or native `<select>`) with `<SearchSelect items valueKey getKey getLabel onSelect placeholder searchPlaceholder emptyText contentClassName="w-[NNNpx] p-0" />`. For an "All X" sentinel, prepend `{ id:"", name:"All X" }` to items and let `onSelect` receive `""` (drop the old `"all"` sentinel mapping). Wrap filter-row selects in a fixed-width `<div className="w-[NNNpx]">`. The popover portals (base-ui Popover), so it is NOT clipped inside dialogs — verified.

**Inventory — shadcn `<Select>` / native `<select>`:** Stock (stock-journal, stock-dialogs), Invoices (invoice-generate, invoice-matcher-row[native]), Tasks (task-create-dialog, task-assignee-select, tasks-filters[native]), Users&Teams (super-admin add-user / add-team[native] / manage-members[native]), Customers (customer-status-form, ledger-edit-collection-fields), Market Intelligence (note-fields, item-rows), Orders (orders-download), Audit Logs (audit-select), Errors (error-detail-drawer[native]).

**ALSO in scope — `TextSelect` (`@/components/text-select`, the non-searchable styled dropdown; MISSED in the first grep since it is neither `<Select>` nor `<select>`):** customers-filter-bar, super-admin-sections ×2 (done), orders/order-oil-line-row ×2, collections/collection-payment-fields, collections/collections-filter-bar, expenditures/expenditure-filters. Convert these to SearchSelect per-page too (its options `[{value,label}]` map directly to items/getKey=value/getLabel=label; consumers already use an "all" sentinel so pass it straight through). Leave the `TextSelect` component file itself in place until its last call site is gone.
